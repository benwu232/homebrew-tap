# Homebrew Tap for Phantom Knob

Official Homebrew Tap for [Phantom Knob](https://github.com/benwu232/PhantomKnob) and macOS utilities.

## Installation

```bash
brew install --cask benwu232/tap/phantom-knob
```

Or add the tap first:

```bash
brew tap benwu232/tap
brew install --cask phantom-knob
```

## Upgrade

```bash
brew upgrade phantom-knob
```

## Uninstall

```bash
# Standard uninstall
brew uninstall phantom-knob

# Complete uninstall (removes app data, preferences, and cache)
brew uninstall --zap phantom-knob
```
